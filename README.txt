SENSI FULL CAPA FF — V2 (ARQUIVOS NA RAIZ)

Conteúdo:
- index.html: aplicativo web responsivo, sem subpastas.
- preview-interface.png: referência visual da interface.

PUBLICAR NO RENDER (Static Site):
1. Envie index.html e preview-interface.png para a raiz do repositório GitHub.
2. Render > New > Static Site > conecte o repositório.
3. Root Directory: deixe em branco.
4. Build Command: deixe em branco.
5. Publish Directory: .
6. Clique em Create Static Site.

FUNÇÕES:
- Catálogo inicial de modelos de telefones de marcas conhecidas.
- Gerador local de sensibilidade e DPI sugerida.
- Sliders, botões +/- para valores.
- Toggle de ajuste de controle (perfil interno; não altera a mira do jogo).
- Ajuste por feedback de teste.
- Copiar valores.
- Salvar, abrir e apagar perfis no histórico local (até 30 entradas).

NOTA: Valores são recomendações experimentais. A aplicação não altera configurações do Free Fire nem a DPI do sistema automaticamente.
